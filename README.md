## Описание проекта

АИС «Электронная библиотека» — система для ведения реестра книг и читателей, поиска книг и оставления рецензий.

### Функциональность

- Просмотр каталога книг с пагинацией (10 книг на страницу)
- Поиск и фильтрация книг по названию, автору, жанру, году и объёму страниц
- Добавление, редактирование и удаление книг (в зависимости от роли)
- Загрузка обложек книг с MD5-дедупликацией
- Описание книг и рецензии в формате Markdown (редактор EasyMDE)
- Система ролей: Администратор, Модератор, Пользователь
- Регистрация и авторизация пользователей

## Установка и запуск

```bash
# 1. Клонировать репозиторий
git clone https://github.com/Nastyasolnyyt/exam_task_web
cd exam_task_web

# 2. Создать виртуальное окружение
python3.12 -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Инициализировать базу данных
python init_db.py

# 5. Запустить приложение
python app.py
```

Приложение будет доступно по адресу: http://127.0.0.1:5000

## Вариант 3 — Поиск книг

На главной странице реализована форма поиска со следующими полями:

- **Название** — поиск с частичным совпадением
- **Автор** — поиск с частичным совпадением
- **Жанр** — мультиселект, варианты из БД
- **Год** — мультиселект, варианты генерируются из БД автоматически
- **Объём от/до** — фильтрация по количеству страниц

При переходе между страницами пагинации фильтры сохраняются.
